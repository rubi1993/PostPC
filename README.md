# PostPC - Gyro Controlled Remote Mouse

A Java-based application that transforms your device into a gyroscope-controlled remote mouse. Control your computer's cursor with intuitive motion gestures using your device's accelerometer and gyroscope sensors.

## Features

- **Gyro-Based Control**: Navigate your desktop using natural motion gestures
- **Precise Cursor Movement**: Smooth and responsive cursor positioning
- **Mouse Click Simulation**: Perform left-click, right-click, and other mouse operations
- **Wireless Connection**: Control your computer remotely over a network connection
- **User-Friendly Interface**: Intuitive controls for seamless interaction

## Technical Stack

- **Language**: Java
- **Platforms**: Cross-platform compatible

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/rubi1993/PostPC.git
   cd PostPC
   ```

2. Compile the project:
   ```bash
   javac *.java
   ```

3. Run the application:
   ```bash
   java Main
   ```

## Usage

1. Launch the PostPC application on your computer
2. Start the companion app on your mobile device (ensure both are on the same network)
3. Tilt and rotate your device to move the cursor
4. Use the on-screen buttons to perform mouse clicks

## How It Works

The application leverages your device's gyroscope and accelerometer sensors to detect motion and orientation changes. These sensor inputs are translated into cursor movements on your computer, providing an intuitive and interactive control experience.

## Requirements

- Java Runtime Environment (JRE) 8 or higher
- Device with gyroscope and accelerometer sensors
- Network connectivity between control device and computer
